# ⚡ LIG DNA 스마트 투두 (Smart Todo App)

> **LIG DNA 워크스페이스 전용 모던 파이썬 Flask 기반 스마트 투두 웹 애플리케이션**

---

## 🌟 주요 기능

1. **대시보드 통계 & 진행률**
   - 전체 할 일, 진행 중, 완료된 항목, 오늘 마감 항목 실시간 집계
   - 목표 달성률(%) 시각적 애니메이션 프로그레스 바 제공
   - 상태별 카드 클릭 시 해당 상태 항목으로 빠른 필터링

2. **할 일 관리 (CRUD)**
   - **간편 등록 (Quick Add)**: 상단 인라인 입력창에서 Enter 키로 즉시 등록
   - **상세 등록 모달**: 제목, 상세 내용, 카테고리, 우선순위, 마감일 지정
   - **수정 & 삭제**: 언제든 카드 우측 버튼으로 손쉽게 수정 및 삭제
   - **완료 체크 & 축하 효과**: 완료 체크 시 파티클 컨페티(폭죽) 애니메이션 효과

3. **스마트 필터링 & 검색**
   - **카테고리**: 🧬 DNA 과제, 💼 업무/프로젝트, 🌱 개인/자기계발, 👥 회의/미팅, 📌 기타
   - **진행 상태**: 전체 / 진행 중 / 완료
   - **정렬 옵션**: 최신 등록순, 마감일 임박순, 우선순위 높은순, 오래된 순
   - **실시간 검색**: 제목 및 본문 실시간 즉각 검색 기능

4. **신뢰할 수 있는 데이터 보관**
   - 표준 경량 데이터베이스인 SQLite(`todos.db`)를 내장하여 서버 재시작 후에도 데이터 영구 보존

## 📁 디렉토리 구조

```
LIG_DNA_TODO_APP/
├── app.py                  # Flask 백엔드 서버 및 REST API, SQLite DB 연동

├── run.bat                 # 윈도우 더블클릭 실행 스크립트 (브라우저 자동 실행)

├── static/
│   ├── css/
│   │   └── style.css       # 모던 다크 글래스모피즘 스타일시트
│   └── js/
│       └── app.js          # 프론트엔드 비동기 API 통신, 필터링, 애니메이션 로직
└── templates/
    └── index.html          # 메인 반응형 웹 대시보드 템플릿
```

## 🚀 실행 방법

### 방법 1. 더블 클릭으로 바로 실행 (가장 추천)
폴더 내 `run.bat` 파일을 더블 클릭하면 자동으로 브라우저가 열리고 서버가 실행됩니다.

### 방법 2. 터미널 명령어로 직접 실행
```powershell
cd c:\Users\user\Desktop\260916_CLAUDE_RPA\LIG_DNA_TODO_APP
python app.py
```
브라우저에서 `http://127.0.0.1:5000` 으로 접속합니다.
